# Terrain Generation Studio

A procedural terrain generation tool with a Python FastAPI backend and a vanilla JavaScript frontend.

## Prerequisites

- Python 3.8+
- pip (Python package installer)

## Setup

1.  **Clone or navigate** to the project directory:
    ```bash
    cd d:\Projects\3
    ```

2.  **Install dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

## Running the Application

You need to run the **Backend** and **Frontend** in separate terminal windows.

### 1. Backend Server (API)

In the root directory (`d:\Projects\3`), run:

```bash
python -m server.main
```
The API will start at `http://localhost:8000`.

### 2. Frontend Client

Open a **new terminal**, navigate to the client folder, and start a simple HTTP server:

```bash
cd client
python -m http.server 3000
```
Then open your browser to [http://localhost:3000](http://localhost:3000).

## Features

- **Noise Algorithms**: Perlin, Simplex, OpenSimplex.
- **Hydraulic & Thermal Erosion**.
- **Export Formats**: OBJ Mesh, RAW Heightmap (16-bit), PNG Heightmap/Normal Map.

## API Documentation (Swagger UI)

The best way to see all available parameters is to use the **interactive API documentation** automatically generated by the server.

1.  Start the server: `python -m server.main`
2.  Open your browser to: [http://localhost:8000/docs](http://localhost:8000/docs)

This page lists all endpoints (like `/generate_terrain` and `/export_terrain`) and shows:
-   Required and optional parameters
-   Valid value ranges (e.g. `size` between 32 and 1024)
-   Default values
-   Example requests

You can even execute requests directly from this page to test them.

## API Usage (Headless)

If you only want to use the API (e.g. for generating assets in a build pipeline), you can use the provided example script:

1.  Start the server: `python -m server.main`
2.  Run the example client:
    ```bash
    python examples/api_client.py
    ```

This script demonstrates how to request a terrain export and save the resulting OBJ, PNG, and RAW files to disk.

## API Parameter Reference

When using the `/generate_terrain` or `/export_terrain` endpoints, you can include the following parameters in your JSON body:

| Parameter | Type | Default | Range | Description |
| :--- | :--- | :--- | :--- | :--- |
| `seed` | `int` | `42` | Any integer | Random seed for reproducible generation. |
| `size` | `int` | `256` | `32` - `1024` | Resolution of the terrain (width & height). |
| `noise_algorithm` | `string` | `"simplex"` | `"wave"`, `"harmonic"`, `"perlin"`, `"simplex"` | The base noise algorithm. |
| `frequency` | `float` | `3.0` | `0.1` - `20.0` | Base frequency of the noise. |
| `amplitude` | `float` | `1.0` | `0.1` - `2.0` | Height amplitude. |
| `octaves` | `int` | `6` | `1` - `10` | Number of noise layers (detail). |
| `persistence` | `float` | `0.5` | `0.1` - `1.0` | Amplitude falloff per octave. |
| `lacunarity` | `float` | `2.0` | `1.0` - `4.0` | Frequency multiplier per octave. |
| `fractal_type` | `string` | `"fbm"` | `"none"`, `"fbm"`, `"ridged"`, `"billow"` | How octaves are combined. |
| `enable_hydraulic` | `bool` | `false` | `true`/`false` | Simulate water erosion. |
| `enable_thermal` | `bool` | `false` | `true`/`false` | Simulate thermal erosion. |
| `erosion_iterations` | `int` | `30000` | `1000` - `100000` | Number of erosion simulation steps. |
| `erosion_strength` | `float` | `0.3` | `0.1` - `1.0` | Intensity of erosion effect. |
| `enable_secondary_noise` | `bool` | `false` | `true`/`false` | Enable a second noise layer. |
| `secondary_algorithm` | `string` | `"perlin"` | Same as `noise_algorithm` | Algorithm for secondary layer. |
| `secondary_frequency` | `float` | `5.0` | `0.1` - `20.0` | Frequency for secondary layer. |
| `secondary_amplitude` | `float` | `0.5` | `0.1` - `2.0` | Amplitude for secondary layer. |
| `blend_mode` | `string` | `"add"` | `"add"`, `"multiply"`, `"lerp"`, `"min"`, `"max"` | How to combine primary & secondary layers. |
| `blend_weight` | `float` | `0.5` | `0.0` - `1.0` | Mixing weight (0=primary, 1=secondary). |
